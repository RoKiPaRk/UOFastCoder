# uo-report

Generate a UniQuery report + Python report script from a live U2 DICT.

## Arguments

The user invoked this with: $ARGUMENTS

Parse as: `<FILE> [description] [--python-only]`

- `FILE` — U2 file name (e.g. `CLIENTS`, `ORDERS`)
- `description` — optional plain-English description of what the report should show (e.g. "orders by country with totals")
- `--python-only` — skip UniQuery generation, output only the Python script

## Examples

```
/uo-report ORDERS
/uo-report ORDERS orders by country with totals
/uo-report CLIENTS clients grouped by state --python-only
```

## Prerequisites

- UOFastMCP server running
- File exists in Unidata with a populated DICT

---

## Steps

### Step 1 — Read live DICT

Call `mcp__UOFastMCP__get_dict_items`. Collect all D-type fields with:
- Attribute number, column heading, conversion code
- MV flag (attr 8 = `M`)
- I-type computed fields (usable in SELECT/SORT/LIST, cannot be written)

Identify:
- **Numeric fields** (MD/MR conversion or name contains AMOUNT/PRICE/QTY/TOTAL) — candidates for `TOTAL`
- **Date fields** (D conversion) — format with `D4/` or `D2-` as appropriate
- **Category fields** (short text, no special conversion) — candidates for `BREAK-ON` grouping
- **MV fields** — use `EXPLODE` for detail rows or omit from summary reports

### Step 2 — Sample data

Call `mcp__UOFastMCP__query_file` with `limit=5` to see real data shapes and confirm field values.

### Step 3 — Build UniQuery command

If a `description` was given, parse the intent (grouping fields, sort order, totals, filters).

Default report pattern (no description given): list all records sorted by the first categorical field with totals on all numeric fields.

UniQuery rules:
- Always end with `NOPAGE` to suppress page breaks in API/script contexts
- Use `BREAK-ON` before the sort field for group subtotals
- Use `TOTAL` on numeric (MD/MR) fields for column totals
- Use `BY` for primary sort, `BY-DSND` for descending
- Use `WITH <FIELD> = "value"` for filters
- Use `EXPLODE` on MV fields to produce one row per value (only when useful)
- Use `HEADING "Report Title"` for titled output
- Do NOT use `COUNT.SUP` unless explicitly suppressing record counts
- For date ranges: `WITH ORDER_DATE >= "01/01/2025" AND ORDER_DATE <= "12/31/2025"`

Example well-formed command:
```
SORT ORDERS BY COUNTRY BREAK-ON COUNTRY TOTAL AMOUNT ORDER_DATE CUSTOMER_NO AMOUNT NOPAGE
```

### Step 4 — Run the command live

Call `mcp__UOFastMCP__execute_command` with the built command. Show output verbatim.

If the command errors:
- Fix field names (must match DICT exactly)
- Remove any field that caused "Unknown field" errors
- Re-run until output is valid

### Step 5 — Generate Python report script (unless --python-only skips UniQuery)

Write to `reports/<file_lower>_report.py`:

```python
"""
<File> Report — <description or default description>
Generated by UO-Report agent.

Usage:
    python reports/<file_lower>_report.py [--csv] [--json]
"""

import uopy
import os
import csv
import json
import sys
from io import StringIO

UNIDATA_HOST     = os.environ["UNIDATA_HOST"]
UNIDATA_PORT     = int(os.environ.get("UNIDATA_PORT", 31438))
UNIDATA_USERNAME = os.environ["UNIDATA_USERNAME"]
UNIDATA_PASSWORD = os.environ["UNIDATA_PASSWORD"]
UNIDATA_ACCOUNT  = os.environ["UNIDATA_ACCOUNT"]
UNIDATA_SERVICE  = os.environ.get("UNIDATA_SERVICE", "udcs")

UNIQUERY_COMMAND = (
    "SORT <FILE> BY <FIELD> BREAK-ON <FIELD> TOTAL <NUMERIC_FIELD> NOPAGE"
)

def run_report(output_format: str = "text"):
    sess = uopy.connect(
        host=UNIDATA_HOST, port=UNIDATA_PORT,
        user=UNIDATA_USERNAME, password=UNIDATA_PASSWORD,
        account=UNIDATA_ACCOUNT, service=UNIDATA_SERVICE,
    )
    try:
        cmd = uopy.Command(UNIQUERY_COMMAND)
        cmd.run()
        raw = cmd.response
        if output_format == "text":
            print(raw)
        elif output_format == "csv":
            # Parse columnar output into rows
            lines = [l for l in raw.splitlines() if l.strip()]
            writer = csv.writer(sys.stdout)
            for line in lines:
                writer.writerow([c.strip() for c in line.split("  ") if c.strip()])
        elif output_format == "json":
            lines = [l for l in raw.splitlines() if l.strip()]
            rows = [[c.strip() for c in line.split("  ") if c.strip()] for line in lines]
            print(json.dumps(rows, indent=2))
    finally:
        sess.close()

if __name__ == "__main__":
    fmt = "text"
    if "--csv" in sys.argv:
        fmt = "csv"
    elif "--json" in sys.argv:
        fmt = "json"
    run_report(fmt)
```

Customize with the actual UniQuery command, real field names, and meaningful variable names.

- Fields used and why
- Suggested variations (add a date filter, change grouping, export to CSV)
